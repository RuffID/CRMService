# AGENTS

Директория `CRMService.Web/Service` содержит сервисы веб-слоя: фильтры страниц, фоновые службы хоста и настройки, завязанные на файловое окружение веб-приложения.

Основные области:
- `Attributes` — фильтры авторизации и загрузки текущего пользователя для Razor Pages;
- `BackgroundServices` — фоновые задачи, которые запускают прикладную синхронизацию и обновление отчетных данных;
- `Settings` — хранение и выдача пользовательских настроек веб-интерфейса.

Правила изменений:
- веб-сервисы не должны содержать расчетную бизнес-логику, если ее можно вынести в `CRMService.Application`;
- фоновые службы должны создавать scope и получать прикладные сервисы из DI;
- файловые настройки должны проверять входные ограничения и возвращать понятную ошибку через ServiceResult.
