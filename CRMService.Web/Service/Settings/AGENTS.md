# AGENTS

Директория содержит веб-настройки, которые зависят от окружения приложения.

Сейчас здесь хранится сервис фона отчета:
- принимает загрузку изображения;
- хранит только один актуальный файл;
- удаляет старый фон при загрузке нового;
- отдает метаданные и содержимое файла для страницы отчета и страницы настроек.

Связанная логика:
- страница управления фоном находится в `CRMService.Web/Pages/Settings.cshtml`;
- клиентский код загрузки и предпросмотра находится в `CRMService.Web/wwwroot/js/settings/siteSettings.js`;
- использование фона в отчете находится в `CRMService.Web/Pages/Report.cshtml`.

Правила изменений:
- сохранять ограничение на один активный фон, если не меняется продуктовый сценарий;
- проверять формат и размер файла до сохранения;
- при изменении пользовательского сценария обновлять `README.md`.
