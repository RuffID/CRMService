# AGENTS

Директория `Pages/Issues` отвечает за UI списка заявок и страницу карточки заявки.

Что здесь находится:
- `Index` — AJAX-only список заявок с фильтрами, поиском, постраничной навигацией и сохранением состояния таблицы;
- `Details` — страница маршрута `/issues/{id}` для перехода из списка в карточку заявки и возврата обратно на нужную страницу.

Пользовательский сценарий:
- пользователь ищет заявки по номеру или теме;
- фильтрует список по типу, статусу, клиенту, приоритету, ответственному, автору, группе и датам;
- открывает карточку заявки из таблицы;
- возвращается назад к той же странице списка.

Связанная логика:
- серверная выборка списка и карточки находится в `CRMService.Application/Service/OkdeskEntity/IssueService.cs`;
- клиентский код списка находится в `CRMService.Web/wwwroot/js/issues/issues.js`;
- клиентский код карточки находится в `CRMService.Web/wwwroot/js/issues/details.js`;
- DTO списка и карточки находятся в `CRMService.Contracts/Models/Dto/OkdeskEntity`.

Правила изменений:
- список и карточка должны придерживаться общего паттерна Razor Pages + отдельный JavaScript в `wwwroot/js/issues`;
- данные для UI загружать только через PageModel handlers, без серверного рендера динамических коллекций;
- при доработке списка сохранять стабильность query-параметра `page`, чтобы навигация из карточки возвращала пользователя на исходную страницу;
- таблица списка должна оставаться читабельной в пределах видимой области: поддерживать горизонтальный скролл, сохранение ширин колонок и ручной ресайз.
