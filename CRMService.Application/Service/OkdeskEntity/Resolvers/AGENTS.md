# AGENTS

Директория содержит resolver-сервисы для восстановления ссылок на локальные сущности Okdesk.

Resolver нужен, когда входящая заявка, оборудование или вебхук ссылается на справочник, которого еще нет в локальной базе. Сервис сначала пытается найти сущность локально, затем запускает целевую синхронизацию и повторяет поиск.

Связанная логика:
- общая защита от параллельных обновлений находится в `CRMService.Application/Service/Sync`;
- сервисы загрузки конкретных справочников находятся уровнем выше в `CRMService.Application/Service/OkdeskEntity`;
- обработчики вебхуков находятся в `CRMService.Application/Service/Webhook`.

Правила изменений:
- resolver не должен молча подставлять произвольные значения при неразрешенной ссылке;
- добавляя новую зависимость между сущностями, добавлять явное разрешение ссылки в соответствующий resolver;
- синхронизацию одной сущности выполнять через общий механизм блокировки, чтобы параллельные события не запускали дублирующие обновления.
