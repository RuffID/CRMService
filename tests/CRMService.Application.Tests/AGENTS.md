# CRMService.Application.Tests

Проект содержит быстрые unit-тесты прикладной логики. Единственная `ProjectReference` ведёт на `CRMService.Application`; локальная compile-time ссылка на `EFCoreLibrary.dll` нужна для публичных базовых интерфейсов Domain-сущностей и не разрешает использовать EF provider или контекст. Внешние зависимости заменяются контролируемыми doubles. Используются xUnit v3 и Microsoft.Testing.Platform через `CRMService.Testing.props`.

Реальная сеть, БД и Docker запрещены. Будущие контейнерные тесты сюда не добавляются; общий trait и команды фильтрации определены в `tests/AGENTS.md`.

Границы доступа к данным проверяются через узкие сценарные Unit of Work и read-only source-контракты; fake глобального Unit of Work не создавать.

Builders хранятся локально по предметным областям и создают новый минимально валидный объект для каждого теста. NSubstitute использовать для узких интерфейсов; настраивать только реально вызываемые члены и проверять сохранение, транзакционные и внешние границы сценария.
