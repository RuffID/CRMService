# AGENTS

Директория содержит сервисы локальной работы с сущностями Okdesk и связанными справочниками.

Основные сущности:
- заявки, статусы, приоритеты, типы и группы типов;
- оборудование, параметры оборудования, типы, производители и модели;
- клиенты, категории клиентов и объекты обслуживания;
- сотрудники, группы, роли и связи сотрудников с группами;
- списания времени.

Основные сценарии:
- получение списков и карточек для UI;
- загрузка данных из Okdesk API;
- загрузка данных из облачной базы Okdesk;
- создание или обновление локальных копий сущностей;
- подготовка lookup-списков для фильтров страниц.

Связанная логика:
- списки заявок и оборудования находятся в `CRMService.Web/Pages/Issues` и `CRMService.Web/Pages/Equipments`;
- API-контроллеры справочников находятся в `CRMService.Web/Controllers/OkdeskEntity`;
- доменные модели находятся в `CRMService.Domain/Models/OkdeskEntity`;
- маппинги DTO находятся в `CRMService.Application/Common/Mapping/OkdeskEntity`.

Правила изменений:
- обновления должны быть идемпотентными и не создавать дубли при повторном запуске;
- для зависимых сущностей сначала разрешать ссылки через локальные справочники или resolver-сервисы;
- при изменении списка полей, которые видит пользователь, обновлять соответствующий локальный `AGENTS.md` страницы.
