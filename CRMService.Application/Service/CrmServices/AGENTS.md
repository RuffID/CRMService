# AGENTS

Директория содержит сервисы внутренних CRM-настроек, не являющихся прямой копией Okdesk.

Основной сценарий:
- управление планами сотрудников;
- настройка общего интервала переключения планов в отчете;
- сохранение плановых значений по сотрудникам;
- настройка цветовых правил выполнения плана.

Связанная логика:
- страница настроек планов находится в `CRMService.Web/Pages/PlanSettings.cshtml`;
- клиентский код страницы находится в `CRMService.Web/wwwroot/js/settings/planSettings.js`;
- доменные модели планов находятся в `CRMService.Domain/Models/CrmEntities`.

Правила изменений:
- сохранять планы, значения сотрудников и цветовые правила как единый пользовательский сценарий;
- не смешивать настройки планов с расчетом отчетов: отчеты только используют сохраненные настройки;
- при изменении смысла планов обновлять описание страницы в `README.md`.
