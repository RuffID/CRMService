# AGENTS

Директория содержит общие Razor-фрагменты страниц.

Что здесь находится:
- общий layout с боковым меню, верхней панелью, локальным подключением Bootstrap, Bootstrap Icons, jQuery и общих скриптов;
- частичный шаблон клиентской валидации.

Правила изменений:
- изменения layout влияют на все страницы, поэтому сначала проверять меню, авторизацию и подключение общих скриптов;
- шрифты Bootstrap Icons должны оставаться рядом с `bootstrap-icons.css` в `wwwroot/lib/bootstrap/dist/css/fonts`, поскольку CSS использует относительные URL;
- пункты меню должны соответствовать реальным страницам и ролям пользователя;
- общий JavaScript подключать здесь только если он нужен большинству страниц.
