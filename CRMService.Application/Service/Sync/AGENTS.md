# AGENTS

Директория содержит общий механизм синхронизации сущностей.

`EntitySyncService` защищает обновление одной и той же сущности от параллельного выполнения. Это важно для вебхуков и resolver-сервисов, где несколько событий могут одновременно попытаться догрузить или обновить один и тот же объект.

Правила изменений:
- ключ блокировки должен однозначно соответствовать типу и идентификатору сущности;
- не использовать этот сервис для долгих независимых операций, если они не конфликтуют по одной сущности;
- при добавлении новых сценариев синхронизации проверять, что блокировка не создает лишнюю последовательность для разных объектов.
