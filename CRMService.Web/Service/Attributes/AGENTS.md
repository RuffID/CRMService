# AGENTS

Директория содержит фильтры Razor Pages.

Что здесь находится:
- проверка cookie-авторизации для страниц;
- загрузка текущего пользователя в PageModel, если страница реализует соответствующий контракт.

Связанная логика:
- регистрация авторизации находится в `CRMService.Web/Core/ServiceCollectionExtensions.cs`;
- модели пользователей находятся в `CRMService.Domain/Models/Authorization`;
- страницы используют эти фильтры через общие настройки Razor Pages и PageModel.

Правила изменений:
- для API не подменять ошибки авторизации редиректами, если ожидается HTTP-статус;
- при загрузке пользователя учитывать роли, потому что меню и доступы зависят от них;
- текущий пользователь с ролями загружается через `AuthenticationService`, без прямого доступа фильтра к repository/Unit of Work;
- не добавлять в фильтры бизнес-операции, не связанные с доступом и контекстом пользователя.
