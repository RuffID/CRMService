# AGENTS

Директория отвечает за расчет отчетов, которые отображаются на странице `Отчёт`.

Что здесь считается:
- производительность сотрудников за период;
- динамика списанного времени по сотрудникам или группам;
- динамика созданных и решенных заявок.

Связанная логика:
- страница отчета находится в `CRMService.Web/Pages/Report.cshtml`;
- клиентский код отчетов находится в `CRMService.Web/wwwroot/js/reports`;
- агрегирующие репозитории находятся в `CRMService.Infrastructure/DataBase/Repository/Report`;
- report services используют `IReportsUnitOfWork`, ограниченный report repositories и нужными employee/plan references;
- DTO отчетов находятся в `CRMService.Contracts/Models/Dto/Report`.

Правила изменений:
- расчет отчета должен опираться на локальные данные CRM;
- фильтры отчета должны соответствовать параметрам, доступным на странице;
- отчет производительности по умолчанию исключает неактивных сотрудников; пользовательский выбор фильтра активности хранится клиентом вместе с остальными фильтрами;
- отчет производительности может добавлять закрепленную внизу виртуальную строку с общим количеством открытых заявок без сотрудника по выбранным ответственным группам; строка считается по локальным заявкам, не участвует в количестве сотрудников, не содержит плана, решенных заявок и списанного времени и скрывается фильтром текущих заявок только при нулевом количестве;
- при добавлении нового отчета обновлять страницу, клиентский переключатель отчетов, PageModel handlers и `README.md`.
