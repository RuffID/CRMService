# Okdesk source models

Директория содержит read-only модели строк SQL API Okdesk. Эти модели описывают внешний контракт хранения и не являются локальными доменными сущностями `MainContext`.

Правила:
- внешний `id` хранить в явно названном поле модели источника и преобразовывать в локальные идентификаторы в application service;
- не использовать source-модели как tracked-сущности `MainContext`;
- изменения схемы сверять с документацией SQL API Okdesk и соответствующей конфигурацией `OkdeskContext`.
