# AGENTS

Директория содержит прикладные сценарии, которые запускаются фоновыми задачами или ручными административными командами.

Основной сервис обновляет локальные справочники и сущности из внешних источников: типы оборудования, параметры, производителей, модели, категории, клиентов, объекты обслуживания, роли, группы, сотрудников, заявки и списания времени.

Связанная логика:
- фоновые оболочки находятся в `CRMService.Web/Service/BackgroundServices`;
- ручная команда запуска находится в `CRMService.Web/Controllers/Hosted`;
- сервисы конкретных сущностей находятся в `CRMService.Application/Service/OkdeskEntity`.

Правила изменений:
- порядок обновления важен, потому что часть сущностей ссылается на уже загруженные справочники;
- не скрывать ошибки синхронизации мягкими fallback-ветками, сначала исправлять первопричину;
- при добавлении нового справочника явно определить его место в общем порядке обновления.
