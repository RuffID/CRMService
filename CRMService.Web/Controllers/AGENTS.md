# AGENTS

Директория содержит API-контроллеры веб-слоя.

Правила изменений:
- контроллеры должны оставаться тонкой HTTP-оберткой над прикладными сервисами;
- контроллеры не получают repositories или Unit of Work напрямую; выборки и сохранение координируются Application services;
- долгие массовые обновления из эндпоинтов нужно запускать через `BackgroundUpdateService`, чтобы запрос сразу возвращал ответ;
- для фоновых запусков не передавать scoped-сервис из контроллера в `Task.Run`; сервис нужно получать из нового DI scope внутри `BackgroundUpdateService`;
- повторный запуск той же массовой операции должен возвращать конфликт, пока текущая операция не завершилась.
- обновление параметров оборудования из REST API затем привязывает `OkdeskId` из SQL API и только после этого синхронизирует связи параметров с типами оборудования;
- `IssueController` позволяет администратору вручную запустить сверку существования текущих локальных заявок с Okdesk; endpoint ожидает завершения того же прикладного сценария, что использует ежедневная фоновая задача, и отменяет его при разрыве HTTP-запроса.
