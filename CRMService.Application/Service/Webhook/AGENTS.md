# AGENTS

Директория содержит обработчики входящих событий Okdesk.

Что обрабатывается:
- создание, изменение и удаление заявок;
- изменение статуса заявки и списания времени;
- обновление клиентов;
- обновление объектов обслуживания;
- обновление оборудования.

Связанная логика:
- входная точка вебхука находится в `CRMService.Web/Controllers/WebHook/WebhookController.cs`;
- модели входящих событий находятся в `CRMService.Application/Models/WebHook`;
- обновление конкретных сущностей выполняется сервисами из `CRMService.Application/Service/OkdeskEntity`;
- параллельные обновления защищает `CRMService.Application/Service/Sync`.

Правила изменений:
- обработчик должен явно определить, умеет ли он обработать событие;
- повторная доставка одного события не должна приводить к дублям;
- если событие несет зависимую сущность, сначала обеспечить корректное разрешение ее ссылок.
