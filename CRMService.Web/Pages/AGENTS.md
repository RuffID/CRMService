# AGENTS

Инструкции для Razor Pages в директории `Pages`.

Правила оформления страниц:
- не размещать `CSS` прямо в `.cshtml`;
- не использовать inline-стили в Razor-разметке для новых изменений;
- стилизацию выполнять только через Bootstrap-классы и Bootstrap-утилиты;
- если для задачи не хватает Bootstrap без кастомного `CSS`, сначала отдельно согласовать такое исключение.

Правила для JavaScript:
- не размещать JavaScript-код прямо в `.cshtml`;
- не использовать inline-обработчики событий в разметке;
- скрипты страницы всегда выносить в отдельные файлы в `wwwroot/js`;
- для динамического DOM придерживаться принятого в проекте подхода без `innerHTML`.

Правила изменений:
- при доработке страницы сначала проверять, нет ли уже отдельного `.js` для этой страницы;
- новые визуальные решения строить на существующих Bootstrap-компонентах;
- не добавлять в страницу локальные `<style>` и `<script>` блоки.
- если изменения затрагивают только `.cshtml` и `.js` страницы, не запускать `dotnet build` только ради таких правок.
