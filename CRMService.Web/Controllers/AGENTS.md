# AGENTS

Директория содержит API-контроллеры веб-слоя.

Правила изменений:
- контроллеры должны оставаться тонкой HTTP-оберткой над прикладными сервисами;
- долгие массовые обновления из эндпоинтов нужно запускать через `BackgroundUpdateService`, чтобы запрос сразу возвращал ответ;
- для фоновых запусков не передавать scoped-сервис из контроллера в `Task.Run`; сервис нужно получать из нового DI scope внутри `BackgroundUpdateService`;
- повторный запуск той же массовой операции должен возвращать конфликт, пока текущая операция не завершилась.
